# Archived: Quaternius Ultimate Nature Pack (45 models)

The first forest used 45 FBX files from the Quaternius "Ultimate Nature Pack" (CC0 1.0, see `License.txt`). The forest was
moved to the Quaternius **Stylized Nature MegaKit** (`unity/Assets/App/Forest/Art/MegaKit`). These files are kept only for
reference and history; they live outside `unity/Assets`, so Unity does not import them and no `.meta` files exist for them.
To use one again, copy it back under `unity/Assets` and let Unity create its `.meta`.
